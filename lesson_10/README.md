# Проект: Автотесты магазина и калькулятора

Проект содержит UI-тесты для проверки работы калькулятора и интернет-магазина с использованием Selenium, Pytest и Allure.

## Базовый синтаксис Markdown

В этом файле используется язык разметки Markdown. Вот его основные элементы:
- `# Заголовок` — создает заголовок первого уровня.
- `## Заголовок` — создает заголовок второго уровня.
- `**жирный текст**` — делает текст **жирным**.
- `*курсив*` — делает текст *курсивом*.
- `- элемент` — создает маркированный список.
- Одинарные обратные кавычки — выделяют код (например, `driver`).
- Тройные обратные кавычки — создают блок кода с подсветкой.

## Установка зависимостей

Перед первым запуском установите необходимые библиотеки. Выполните команду:
`pip install -r requirements.txt`

## Запуск тестов с формированием отчета Allure

Чтобы запустить все тесты и сохранить данные для отчета, выполните команду:
`pytest --alluredir=allure-results -v`

## Просмотр сформированного отчета

Чтобы открыть красивый HTML-отчет в браузере, выполните:
`allure serve allure-results`

### Что вы увидите в отчете Allure:
- **Структуру**: Все тесты разбиты на фичи (Магазин, Калькулятор).
- **Шаги**: Подробное описание каждого действия (например, Ввод логина, Нажатие кнопки Checkout).
- **Результаты проверок**: Успешно ли прошли проверки (assert).
